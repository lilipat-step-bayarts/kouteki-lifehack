## 1. このシステムが作られた背景と目的（Antigravityへのコンテキスト共有）

このプログラム（`local_pc_x_automation/`）は、私たちが運営する以下3つのWebメディア（Cloudflare Pagesでホスティング、GitHub Actionsで毎朝5記事ずつ自動生成・公開）のX（旧Twitter）運用を、**X APIの従量課金（Pay-Per-Use）を一切使わずに完全無料（$0.00）で全自動化する**ために作られました。

### なぜクラウドAPIから「別PCのローカルブラウザ自動操作」へ移行したのか？
1. **X APIのクレジット消費問題**：
   - X API v2の従量課金では、ポスト送信（1回 $0.01）だけでなく、フォロワー一覧取得（`GET /2/users/:id/followers`）やキーワード検索（`GET /2/tweets/search/recent`）の読み取り課金（Read）が非常に高額で、数日でクレジット上限（`HTTP 402: credits depleted`）に達してしまう問題が発生しました。
2. **解決策（クラウドとローカルPCの役割分担）**：
   - **クラウド側（GitHub Actions `lilipat-step-bayarts/kouteki-lifehack`）**：
     - 毎朝の記事自動生成（1日5記事）とCloudflare Pagesへのビルド・デプロイのみを担当（完全無料）。
     - **クラウド側のX APIによる投稿・フォロー処理はすべて解除（停止）済み。**
   - **別PCローカル側（この `local_pc_x_automation` フォルダ）**：
     - Pythonの **Playwright（Chromiumブラウザ自動操縦）** を使い、人間がブラウザで操作するのと全く同じ仕組みで「記事の時間差ポスト」「新規フォロワーのフォローバック」「同ジャンル関心層の検索＆フォロー」「30日間フォローバックがない片思いアカウントの自動フォロー解除」を実行する（**API消費 $0.00**）。
     - Gitや環境変数の複雑な設定をしなくても、**このフォルダを別PCにコピーするだけで、インターネット経由でGitHub上の最新 `articles.json` を自動取得して投稿できるスタンドアロン設計**になっている。

## 3. プログラム構成と各ファイルの役割

* **`x_browser_bot.py`**：メインプログラム本体
  - `fetch_articles_for_account()`：GitHubのRaw URL（`https://raw.githubusercontent.com/lilipat-step-bayarts/kouteki-lifehack/main/.../articles.json`）から各店舗の最新記事一覧をリアルタイム取得。
  - `step0_post_scheduled_article()`：未投稿の記事を1つ選び、時間帯に合わせたフック文面＋記事URL＋ハッシュタグを生成してブラウザ（`https://x.com/intent/post` または `compose/post`）から自動投稿。
  - `step1_auto_followback()`：`https://x.com/<handle>/followers` を開き、「フォローバック（Follow back）」ボタンが出ている新規フォロワーを1回最大3名まで自動フォロバ。
  - `step2_search_and_follow_targets()`：各店舗の同ジャンル検索ワード（最新タブ `f=live`）を開き、投稿者のプロフィールへ遷移して1回最大4名まで自動フォローし、フォロー日時を `local_x_state.json` に記録。
  - `step3_cleanup_non_reciprocators()`：`local_x_state.json` を確認し、**こちらからフォローして30日以上経過した相手**のプロフィールを開き、`[data-testid="userFollowIndicator"]`（「フォローされています」バッジ）がない片思いアカウントを1回最大3名まで自動アンフォローし、`unfollowed` リストに記録して再フォローを永久防止。
* **`setup_and_login.bat`**：初回セットアップ＆3アカウントのログインセッション保存用バッチファイル
* **`run_auto_follow.bat`**：定時実行用ランチャー（投稿＋フォロバ＋新規フォロー＋30日片思い解除を一括実行）
* **`browser_profiles/`**：Playwrightが自動生成するアカウント別専用Chromeプロファイル保存先（Cookie・ログイン状態を保持）
* **`local_x_state.json`**：投稿済み記事ID・日次投稿回数・フォローしたユーザーIDとフォロー日時・アンフォロー済みIDを永続化するステートファイル
