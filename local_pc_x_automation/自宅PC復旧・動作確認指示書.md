## 🛠️ ご自身で手動で確認・復旧する場合の手順（3ステップ）

もしAIを使わずご自身で確認する場合は、以下の手順で1発で復旧できます。

### ステップ1：最新コードの取得
`local_pc_x_automation` フォルダがある場所でターミナル（PowerShell / コマンドプロンプト）を開き、以下を実行します：
```bash
git pull origin main
```
※これで最新の投稿ボタン対応コード、リプライ分割投稿コード、イケロの最新ドメインURLが同期されます。

### ステップ2：初回ログインの確認（セッション切れ解消）
もしXのログインが切れていると投稿ボタンが押せません。
```cmd
setup_and_login.bat
```
を実行し、ブラウザが開いたらXのホーム画面が正常に表示されているか確認します（ログイン画面が出ていたらログインしてEnterを押す）。

### ステップ3：即時テスト投稿（制限解除モード）
「時間が来るまで投稿されない」「待ち時間制限でスキップされる」を防ぐため、以下のコマンドで即座に1件テスト投稿させます：

```bash
# 1号店（ほぽりん）のテスト投稿
python x_browser_bot.py --account store1_hoporin --force --post-only

# 2号店（イケロ）のテスト投稿
python x_browser_bot.py --account store2_ikero --force --post-only
```

黒い画面に：
- `【親ポスト本文（リンクなし・高露出）】`
- `【ツリー返信（リプ欄URL・ペナルティ回避）】`
- `🎉 ブラウザから親ポスト（イラスト画像添付済）を送信しました！`
- `✅ ツリー（リプ欄）へのリンクURL返信が完了しました！`

と表示されれば、完全復旧・大成功です！
