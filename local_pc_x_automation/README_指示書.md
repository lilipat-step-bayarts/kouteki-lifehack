# 【完全無料 $0.00】自宅PC用 X（旧Twitter）3アカウント自動フォロー＆フォロバ＆片思い整理システム（作成・導入指示書）

このフォルダには、Xの有料APIを一切使わず（**APIクレジット消費 $0.00**）、ご自宅のPCのブラウザ（Playwright / Chromium）を使って人間と同じ操作で安全に「自動フォローバック」「同ジャンル関心層フォロー」「14日〜30日フォロバなしの自動フォロー解除」を行う完成品プログラム一式が入っています。

---

## 方法A：ローカルのAntigravityにそのままコピペして渡す指示書（プロンプト）

ご自宅のPCで動かしているローカルのAntigravityに、以下の枠内の文章をそのままコピー＆ペーストして送信するだけで、セットアップからWindowsの自動定期実行（タスクスケジューラ登録）まで全自動で構築してくれます！

```text
GitHubリポジトリ `https://github.com/lilipat-step-bayarts/kouteki-lifehack.git` の中にある `local_pc_x_automation` フォルダを私のPCのデスクトップ（または作業フォルダ）に取得し、以下の手順で3アカウント（1号店: @ramune_lilipat、2号店: @ikero_lab、3号店: @Onigon_yfks）のブラウザ自動フォロー＆フォロバ＆片思い整理ボットをセットアップしてください。

1. Pythonの `playwright` パッケージをインストールし、`playwright install chromium` を実行してください。
2. `local_pc_x_automation/x_browser_bot.py` の設定で、片思い解除日数を30日（または14日）に調整できるようにし、まず初回ログイン保存モード（`--login`）で3アカウントそれぞれの専用ブラウザプロファイル（`browser_profiles/store1_hoporin`, `store2_ikero`, `store3_onigon`）を作成・ログイン待機させてください。
3. 私が3つのアカウントにログインし終わったら、1日3回（例：12:30、19:30、22:30）に自動で `python x_browser_bot.py --account all` が実行されるようにWindowsのタスクスケジューラ（またはMacのlaunchd/cron）へ自動登録してください。
4. 注意点として、1号店（@ramune_lilipat）と2号店（@ikero_lab）は相互フォロー保護対象にし、3号店（成人向け @Onigon_yfks）は1・2号店と完全に分離して夜間のみ動くようにしてください。
```

## 方法B：ご自身でダブルクリックするだけで動かす手順（3分）

このフォルダ（`local_pc_x_automation`）をご自宅のWindows PCにダウンロードしたら、以下の2ステップだけで動きます。

### ステップ1：初回のみ（ログイン情報の保存）
1. **`setup_and_login.bat`** をダブルクリックします。
2. 自動で必要なブラウザ部品（Playwright Chromium）がインストールされた後、まず **1号店（`@ramune_lilipat`）用のブラウザ画面** が開きます。
3. 普通にXにログインし、ホーム画面が表示されたら黒い画面（コマンドプロンプト）に戻って **Enterキー** を押します。
4. 続けて **2号店（`@ikero_lab`）**、**3号店（`@Onigon_yfks`）** のブラウザが順番に開くので、同じくログインしてEnterキーを押します。
   - ※各アカウントは完全に独立した専用フォルダ（`browser_profiles/`）に保存されるため、アカウント同士が混ざることはありません！

### ステップ2：毎日の自動実行
- **`run_auto_follow.bat`** をダブルクリックすると、自動でブラウザが立ち上がり、
  1. 新規フォロワーの自動フォローバック（最大4名/回）
  2. 同ジャンル関心層の最新ポスト検索＆自動フォロー（最大5名/回）
  3. 一定期間フォローバックがない片思いアカウントの自動フォロー解除（最大4名/回）
  を人間らしいランダムな待機時間（3〜7秒）を挟みながら実行し、自動で閉じます。
- Windowsの「タスクスケジューラ」に `run_auto_follow.bat` を登録しておけば、毎日決まった時間に完全放置で動き続けます！
